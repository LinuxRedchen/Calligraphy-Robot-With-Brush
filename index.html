01 · 图片处理

二值化工作台

先做这步

9 种算法（Otsu / Sauvola / Niblack / Wolf…），带光照归一化、对比度拉伸、中值去噪、闭运算填孔、骨架描线，可导出 PNG 或 SVG。

拍歪、有阴影的稿子用 光照归一化 + Sauvola；干净扫描件用 Otsu 就够。

binary.py

命令行

同套算法的命令行版，零依赖（只用 Python 标准库），支持批量处理和多格式。

用法：python binary.py in.png -m sauvola -b 31 -k 0.2

02 · 转 G 代码

图片转单线

按笔画描线

把线条抽成笔画，机器一笔一笔描过去。两种方式：中线（线稿用，交叉不断笔、不来回多画）、轮廓（实心图描每个色块外沿）。

线太碎 → 调低阈值或加大「忽略太小的色块」；糊成一片 → 调高阈值。

图片转实心

填充雕刻

一排排平行线填满黑色区域，和奎享「实心图」同原理。关键参数是「每行多少毫米」= 笔头直径，一笔盖一笔、不重不留缝。

奎享的「每毫米多少行」= 1 ÷ 每行毫米。5mm 笔 → 0.2 行/毫米。可选横填/竖填。

03 · 排版与蘸墨

合并工具

2 行 × 4 列

最多 8 份 G 代码拼成一整版，每格标明是字还是画，分别用重/轻两种下压力度，并可整体缩放、调列/行间距。

墨盘固定在原点 (0,0)，整版会自动右移避开墨盘。最后一步自动插蘸墨 + 刮墨。

蘸墨工具

单个文件

给已经导出的 .gcode 按「每画满多少毫米」插一次蘸墨：去墨盘 → 吸墨 → 移开刮墨 → 抬笔回到断点继续画。

墨盘坐标要填墨盘实际位置，不是画纸上的位置。停留设 0 就不插 G4。

蘸墨处理.bat

拖拽即用

命令行版蘸墨：把 .gcode 直接拖到这个图标上，自动生成同名 _蘸墨.gcode。参数在 add_ink.sh 顶部改。

调用 E:\Git\usr\bin\bash.exe，换电脑要改这一行路径。

add_ink.sh

脚本

蘸墨脚本本体，顶部参数区集中配置：墨盘 XY、下压 Z、停留秒数、每多少毫米蘸一次、是否刮墨及方向/距离。

直接跑：./add_ink.sh 飞入1.gcode

机器参数速查（步进电机模式）

项目默认值说明
落笔 Z5Z 越大压得越深。字重可调到 6~7，作画轻可到 3 或 2
抬笔 Z0导出文件里的抬笔高度，一般不动
F 速度10000导出文件里 Z 后面的 F 不是 10000 时，改成那个值
墨盘坐标按实际量量墨盘中心在机器坐标里的 XY，别填纸上位置
蘸墨间隔400 mm累计笔画长度触发，想蘸勤点就调小

导出文件格式（脚本按这个格式插入）

动作G 代码

落笔G1G90 Z5.0F10000
