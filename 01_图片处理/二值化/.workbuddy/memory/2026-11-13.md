- `binary.py` — 零依赖命令行版（仅标准库）：自带 PNG 解码（灰度/RGB/调色板/RGBA，8/16/1/2/4 位，全部 5 种滤波 + 反滤波）与 PGM/PPM 读取，8 位灰度 PNG 输出，与网页版同一套算法与前后处理。

## 关键实现决定

- 预览最长边限制 1500px 保证交互流畅，导出时按原图全分辨率重算。
- 局部阈值用积分图 O(1) 取窗口均值/方差；Bernsen 的局部 min/max 用单调队列（水平+垂直分离）O(n)。
- Wolf–Jolion 用全局最小灰度 Mmin 补偿低对比度；Niblack 的 k 取负值（默认 -0.2）。
- 光照归一化 = 大窗口(短边/8)均值作背景估计 + 除法拉伸到 205 白场，可调强度。
- 去小连通块用迭代 BFS（4 邻接），面积阈值默认 20px。
- Otsu 在阈值平台区取最小值（与 OpenCV 一致）。
- 预处理结果按参数 key 缓存，滑块拖动只重算二值化。

## 线条顺滑（骨架描线）— 第三轮迭代新增

用户需求："丝滑一条线下去，不要断连、不要凹陷"。新增「线条顺滑」模块：

- 流程：膨胀(连接细缝) → Zhang-Suen 细化 → 提主干 → 端点拼接 → RDP 简化 → 拉普拉斯平滑 → Catmull-Rom 贝塞尔绘制（2x 超采样后缩回，灰度边缘抗锯齿）。
- 关键踩坑：Zhang-Suen 在斜线上必然留下 2px 阶梯，骨架像素的 8 邻域度数高达 3~4，**不能用度数判断分支点**。第一版按度数找分支 + 最短路提取，彻底失效。
- 正确做法：① 每个连通块用"方向连续性走线"（每步选与上一步夹角最小的未访问邻居）提取主干，天然绕过毛刺、不受阶梯影响；② 多段断线用 joinPaths 按 4 种端点组合贪心拼接（也顺带把闭环两端拼上）；③ 毛刺修剪长度实际用作"最短线段过滤"。
- 曾试过"最远点对 + BFS 最短路"提取主干，在 2px 阶梯骨架上路径会抄近道打碎环，放弃；token 标记复用也有隐蔽冲突，改为每轮显式 avail 数组后才稳定。
- 绘制输出保留抗锯齿灰度（不是 0/255），丝滑感来自 2x 超采样 + 灰度边缘；统计黑像素按 <128。
- 新增「下载 SVG」：路径坐标按原图/预览比例缩放输出矢量曲线，供描线/雕刻/打印。
- 参数：线宽(0.6-12)、平滑度(0-6 迭代)、断点连接距离(0-30)、毛刺修剪(0-40)。
- 导出 PNG 描线模式限制 4M 像素内（超大图先降采样，防骨架化卡死）。
- 固有局限：文字笔画骨架化后会变形难读，UI 已注明。
